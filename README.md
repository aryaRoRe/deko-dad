# Deko Dad

دستیار وب و ربات تلگرام دکو. نسخهٔ رایگان با منو و پاسخ‌های فارسی و انگلیسی کار می‌کند. مشتری و فروشنده می‌توانند از وب یا تلگرام درخواست بدهند. هر درخواست یک شمارهٔ پیگیری دارد و پاسخ تیم از همان مسیر به کاربر برمی‌گردد. اطلاعات سفارش واقعی فقط پس از اتصال سامانهٔ سفارش در دسترس خواهد بود.

## ۱. مخزن GitHub

فایل‌های پروژه را در ریشهٔ مخزن خصوصی **deko-dad** قرار دهید. شاخهٔ اصلی **main** است. در تب **Actions**، آزمایش‌های **Test DEKO Dad** پس از ثبت تغییرات اجرا می‌شوند. همکاری وب و تلگرام قبل از راه‌اندازی واقعی با درگاه آزمایشی تست می‌شود.

## ۲. اجرای رایگان از روی مخزن

این پروژه یک سرور دارد. برای اجرای رایگان آن می‌شود از طرح Free در Cloudflare Workers و پایگاه دادهٔ D1 استفاده کرد. دامنهٔ پایهٔ Worker برای شروع کافی است. محدودیت‌های مصرف طرح رایگان را در [صفحهٔ محدودیت‌های Workers](https://developers.cloudflare.com/workers/platform/limits/) و [سقف‌های D1](https://developers.cloudflare.com/d1/platform/limits/) ببینید.

- در Cloudflare یک پایگاه دادهٔ D1 به نام **deko-dad** ایجاد کنید و شناسهٔ آن را بردارید.
- از بخش **Workers & Pages** مخزن GitHub را با [اتصال Cloudflare به GitHub](https://developers.cloudflare.com/workers/ci-cd/builds/git-integration/github-integration/) انتخاب کنید. نام Worker را **deko-dad** بگذارید.
- در تنظیمات ساخت، Node 24 را انتخاب کنید. **Build command** را روی **npm test** و **Deploy command** را روی **npm run deploy:cloudflare** بگذارید. **DEKO_D1_DATABASE_ID** را در متغیرهای ساخت وارد کنید. دستور انتشار ابتدا جدول‌ها را ایجاد یا به‌روزرسانی می‌کند و سپس Worker را منتشر می‌کند.
- برای پنل تیم، **DEKO_TEAM_PASSWORD** را در تنظیمات محرمانهٔ Worker ثبت کنید. یک رمز اختصاصی قوی با حداقل ۱۶ نویسه انتخاب کنید. نشانی پنل، مسیر **/staff** کنار نشانی Worker است. در **تنظیمات دستیار** لینک‌های رسمی و پاسخ‌های تأییدشده قابل تغییرند.

برای اجرای مستقل با Node.js 24 کافی است در پوشهٔ پروژه **npm start** را اجرا کنید. متغیرها را از **.env.example** به **.env** روی دستگاه خودتان منتقل کنید. مسیر پیش‌فرض چت **http://127.0.0.1:8787/** است. پایگاه SQLite در **data/** ذخیره می‌شود. استقرار عمومی با این روش به نشانی HTTPS و دیسک پایدار نیاز دارد. در Cloudflare داده‌ها در D1 ذخیره می‌شوند.

## ۳. روشن کردن ربات در تلگرام

با [BotFather](https://t.me/BotFather) برای دکو ربات بسازید. توکن ربات و یک مقدار تصادفی مستقلِ حداقل ۳۲ نویسه‌ای را با نام‌های **TELEGRAM_BOT_TOKEN** و **TELEGRAM_WEBHOOK_SECRET** به شکل Secret هم در Worker و هم در مخزن GitHub اضافه کنید. برای Secret دوم از نویسه‌های انگلیسی، عدد، خط تیره و زیرخط استفاده کنید. نشانی HTTPS ای که Cloudflare داده را با نام **DEKO_PUBLIC_ORIGIN** در Variables مخزن بگذارید.

در GitHub وارد تب **Actions** شوید، **Connect Telegram** را انتخاب کنید و **Run workflow** را بزنید. این اقدام Bot API را به Worker وصل می‌کند و نام ربات را در نتیجه نشان می‌دهد. روی دستگاهی که Node دارد، همان اتصال از راه **npm run telegram:connect** با متغیرهای محلی قابل انجام است. اگر ربات از قبل webhook دیگری دارد، دستور تنظیم را متوقف می‌کند تا اتصال قبلی جابه‌جا نشود.

برای بررسی، در ربات **/start** بزنید. بعد **/support** را بزنید و یک پیام آزمایشی بفرستید. باید درخواست تلگرام در پنل تیم ظاهر شود و پاسخ پنل در همان چت تلگرام برسد. پیام‌ها و توکن‌ها را در فایل‌های مخزن وارد نکنید.

## ۴. افزودن دکمه به سایت دکو

در متغیر **DEKO_EMBED_ORIGINS** نشانی دقیق سایت دکو، شامل پروتکل و دامنه، وارد می‌شود. برای چند دامنه از ویرگول استفاده کنید. تگ زیر در قالب مشترک صفحات قرار می‌گیرد. نشانی دستیار را با نشانی Worker خودتان جایگزین کنید.

    <script src="https://assistant.example/widget.js" defer></script>

اگر سایت CSP دارد، میزبان دستیار باید برای script-src، frame-src و img-src مجاز باشد. برای صفحهٔ مستقل دستیار مسیر **/chat** قابل استفاده است.

## توسعه و بررسی

- اجرای محلی با Node.js 24 به نصب وابستگی دیگری نیاز ندارد.
- **npm test** آزمون وب، فارسی و انگلیسی، دسترسی پنل، وب‌هوک تلگرام، تکرار پیام، تلاش مجدد و رفت‌وبرگشت پاسخ تیم را اجرا می‌کند. درخواست‌های آزمایشی به حساب واقعی ارسال نمی‌شوند.
- **npm run build** ماژول Worker را آماده می‌کند. **npm run deploy:cloudflare** مستلزم دسترسی شخصی به Cloudflare و شناسهٔ پایگاه داده است.
- شاخهٔ وب برای تاریخچهٔ همان تب از نشست گفت‌وگو استفاده می‌کند. در تلگرام، گفتگو به شناسهٔ خصوصی همان چت وصل است.
- در اجرای مستقل، کلید OpenAI اختیاری است. با خالی ماندن آن، پاسخ‌گوی رایگان داخلی فعال است.
